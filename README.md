# CALDEK
A calculator that also plays games, even Doom!

Rendered image (Coming soon!!)

## What it is
Caldek is a calculator that can do calculations really fast like a normal calculator but if you press a key combo, it switches to game mode where you have a library of games including the classic doom to play from.

## Why I'm making it
I'm making this calculator since I saw many interesting calculator modifications but I have my motto as "Don't buy it, make it". It will also be a good time to learn chip level designs for PCBs that I will need for FLYDEK v2 (Another project I'm doing for flight simulators!). 

## Planned features
- [ ] Scientific & graphing calculator
- [ ] Menu / launcher (Possibly a cool intro)
- [ ] My own games & Simple games (Snake, Tetris…)
- [ ] Classic Doom

## Hardware (planned)
| Part | Choice |
|---|---|
| Chip | RP2350B |
| Memory | 16 MB flash + 8 MB PSRAM |
| Screen | 2.8" 320×240 SPI (ILI9341) |
| Keys | ~45 keys, matrix with diodes |
| Storage | microSD |
| Power | USB-C (v1) |
| Case | my own design, 3D printed |
